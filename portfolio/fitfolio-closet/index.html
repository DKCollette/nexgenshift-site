WORKING PROTOTYPE
FitFolio AI Closet

A local-first virtual dressing room: catalog your closet, get occasion-based outfit picks, and preview looks with optional AI try-on. Screenshots below are the real running app with demo data.

Objective

Cut the daily "what do I wear" tax: give one person a fast, private way to see their whole closet, get dressed for the occasion, and try looks before committing.

Problem

Deciding what to wear wastes time and money — closets fill with unworn clothes while mornings fill with outfit indecision. Existing tools upload your photos to someone else's cloud.

Solution

A local-first virtual closet. Photos stay in the browser's localStorage; an occasion rules engine ("Dress Me Today") suggests outfits; compare up to 3 looks side by side; optional single-garment AI try-on renders a preview.

Technology

Dependency-free Node API serving a zero-build static UI (plain HTML/JS/CSS). AI try-on runs server-side so the key never touches the browser. Covered by a 29-check smoke contract in the repo.

Verified features

What it does today.

  • Inventory + outfit management in localStorage
  • Occasion rules engine (Dress Me Today)
  • Compare up to 3 looks + favorites
  • Optional single-garment AI try-on (server-side provider integration; multi-pass chain)
  • Demo Mode without a key — uploads, swipes, and outfits all work

Status & honest limits

Working prototype. AI Generate requires a server-side key — without one it shows an explanatory message, never a fake image. Photos are local-only (clear site data before shared captures). Single user; no accounts, no sharing, no payments.
