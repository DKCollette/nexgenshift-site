WORKING PROTOTYPE
iDealHope Recovery

A recovery-support platform: searchable resources, consultation and appointment requests, client goal tracking, and a specialist dashboard. Screenshots below are the real running app with synthetic demo data.

Objective

Lower the first-step barrier: make it easy for someone seeking recovery support — or their family — to find help, ask for a consultation, and track progress in one calm place.

Problem

Finding addiction and mental-health support is overwhelming at the hardest moment: scattered listings, unclear costs, and no clear next step toward a real person.

Solution

A single platform: public resource directory (10+ seeded listings with search, category, and cost filters), validated consultation + appointment request flows, client portal with goals, and a specialist dashboard for clients, consultations, and appointments — with the 988 crisis line always visible.

Technology

Node API serving a static UI with a JSON file store. Seeded specialist/client demo logins; salted-hash auth with role gates; 31-check smoke suite green.

Verified features

What it does today.

  • Searchable/filterable public resource directory (seeded listings)
  • Consultation + appointment request flows (validated)
  • Client portal: roadmap goals CRUD, check-ins, wellness history
  • Specialist dashboard: KPIs, client list, referral lifecycle, tasks, inbox
  • 988 crisis banner always visible

Status & honest limits

Working prototype with 100% synthetic data — listings are not real providers, and no real patient data may ever be entered. Explicitly NOT HIPAA or 42 CFR Part 2 assessed: needs formal legal/security review, a BAA chain, encryption at rest, secure cookies, and a real session store before any clinical use. Contact-request only — no real-time or secure messaging. Educational content is informational only, not diagnoses or treatment. Not an emergency monitoring service.
