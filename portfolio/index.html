FitFolio AI Closet

Problem: deciding what to wear wastes time and leads to unworn clothes. Solution: a local-first virtual closet — catalog garments, get occasion-based outfit picks, and preview looks with optional AI try-on. Tech: dependency-free Node API + static HTML/JS, photos in browser localStorage, server-side AI key. Status: working prototype; AI Generate needs a key, otherwise full Demo Mode.
